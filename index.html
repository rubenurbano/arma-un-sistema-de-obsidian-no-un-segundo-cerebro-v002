🚀 Bienvenido al Kit Bóveda + Sistema Operativo de IA

Este tutorial práctico te guiará paso a paso para construir un segundo cerebro empresarial y sistema operativo autónomo. Aprenderás a centralizar todo lo que dices y decides en llamadas, videos de YouTube y documentos, haciéndolo buscable en menos de 2 segundos de forma 100% local, privada y económica.

¿Qué vas a construir?

Tu Bóveda de Conocimiento

Un almacén en archivos Markdown ordenados, indexados por un motor SQLite FTS5 de alta velocidad, operado por Claude Code desde tu terminal.

¿Qué problema resuelve?

El olvido y la dispersión

Elimina la pérdida de tiempo buscando qué cliente prometió qué, cómo resolviste un proceso o qué dijiste en un video hace 6 meses.

Requisitos necesarios

Solo 3 herramientas

1) Python 3 (gratis). 2) Node.js LTS (para instalar Claude Code). 3) Tu cuenta de Claude (plan Pro recomendado). No necesitas saber programar.

📖 Cómo utilizar este tutorial paso a paso

Sigue la regla fundamental: EXPLICAR → HACER → COMPROBAR → CONTINUAR.

  • Avanza por las pestañas en orden secuencial.
  • Utiliza los botones de copiar en cada bloque de código y pega exactamente lo indicado.
  • Revisa las comprobaciones de cada paso antes de saltar al siguiente.
  • Si surge un error, consulta la pestaña de ERRORES o pégale el mensaje directo a Claude Code.

💡 Conceptos Clave explicados para Principiantes

No des nada por supuesto. Antes de teclear, comprende qué piezas forman la máquina y por qué cada una está ahí.

Pilar 1

1. ¿Qué es la Bóveda y por qué usa Markdown plano?

Qué es en castellano sencillo: Una carpeta en tu disco rígido repleta de archivos de texto simple (con extensión .md). Cada reunión, cada video y cada proceso es un archivo individual.

Por qué importa: Las bases de datos propietarias (Notion, Google Docs, bases vectoriales en la nube) son vulnerables a cortes de servicio, aumentos de precio y cambios de formato. El texto plano es tuyo para siempre, se respalda con Google Drive, OneDrive o Git, y se puede abrir con cualquier editor (como Obsidian).

Pilar 2

2. ¿Por qué SQLite FTS5 y no Embeddings ni APIs complejas?

Qué es: SQLite es un motor de base de datos ultraligero que viene preinstalado en Python. FTS5 significa Full-Text Search 5: un índice de búsqueda por palabras clave ponderadas mediante el algoritmo matemático BM25.

Ventajas radicales:

  • Cero costo: No pagas tokens a OpenAI o Pinecone por buscar tus propios datos.
  • Velocidad extrema: Devuelve resultados en menos de 2 segundos en tu propio procesador.
  • Sin internet: Busca incluso si te quedas sin conexión.
  • Normalización de tildes: Con remove_diacritics 2, buscar "metodo" encontrará automáticamente "método".
Pilar 3

3. ¿Qué es Claude Code y qué rol cumple el archivo CLAUDE.md?

Claude Code: Es una herramienta de terminal desarrollada por Anthropic que permite que Claude lea tus archivos locales, ejecute comandos permitidos y edite código en tiempo real.

CLAUDE.md: La memoria inmutable del proyecto. Es el archivo que Claude Code lee automáticamente cada vez que arranca. Sin este archivo, la IA se olvida de la arquitectura, inventa carpetas y al cabo de dos semanas genera un desorden inmanejable.

Pilar 4

4. ¿De Segundo Cerebro a Sistema Operativo de Negocios?

El segundo cerebro es pasivo: guarda lo que sabes y te permite recordarlo. El sistema operativo es activo: se conecta al resto de tus herramientas (correo, YouTube, plataformas de cobro, navegadores) para automatizar acciones y construir pantallas de control (dashboards) personalizadas.

🛠️ Construcción Paso a Paso del Sistema

Sigue cada acción en orden. No te saltes pasos. Si algo falla, Claude Code lo resolverá por ti.

Paso 1: Instalar Python 3 con soporte PATH Acción 1

Python es el motor con el que corren los programas de ingesta y búsqueda local.

Windows Entra a python.org/downloads y descarga el instalador. Al ejecutarlo, MARCA OBLIGATORIAMENTE la casilla "Add Python to PATH".
Mac Abre Terminal (Cmd + Espacio → "Terminal") y escribe python3 --version. Si te pide instalar las herramientas de desarrollador, acepta.
Terminal / PowerShell — Comprobar versión 
python --version
# En Mac usa: python3 --version

Comprobación: La terminal debe responder con un texto similar a Python 3.11.x o superior.

Paso 2: Instalar Node.js y Claude Code Acción 2

Claude Code requiere Node.js LTS para ejecutarse globalmente en tu terminal.

  1. Descarga e instala la versión LTS desde nodejs.org con todos los valores por defecto.
  2. Abre una terminal nueva e instala Claude Code con el comando oficial:
Terminal / PowerShell — Instalación Claude Code 
npm install -g @anthropic-ai/claude-code
Terminal / PowerShell — Primer inicio de sesión 
claude

Comprobación: Al escribir claude por primera vez, se abrirá tu navegador para autenticar tu cuenta de Anthropic.

Paso 3: Instalar yt-dlp y Whisper (Opcional) Acción 3

Herramientas para bajar automáticamente transcripciones de videos y audio de reuniones.

Terminal — Instalar yt-dlp para YouTube 
python -m pip install yt-dlp
# En Mac: python3 -m pip install yt-dlp
🎧 ¿Quieres transcribir audios crudos de reuniones? (faster-whisper)

Si ya utilizas Zoom, Google Meet, Teams o Fathom, no lo necesitas: descarga directamente el archivo .vtt o .txt que ellos te entregan. Solo instala Whisper si tienes grabaciones de voz puras (.mp3, .m4a):

Terminal — Instalar faster-whisper 
python -m pip install faster-whisper
Paso 4: Crear la estructura de carpetas de la Bóveda Acción 4

Crea tu carpeta maestra (por ejemplo mi-boveda) y organízala con la siguiente estructura exacta:

Estructura de la carpeta 
mi-boveda/
├── CLAUDE.md            ← Memoria y reglas de la IA
├── boveda/
│   ├── config.py        ← Configuración única (dueño, canal, marcas)
│   ├── buscar.py        ← Buscador SQLite FTS5 ultra-rápido (< 2s)
│   ├── ingesta_youtube.py
│   ├── ingesta_reunion.py
│   ├── construir_wiki.py
│   ├── _index/          ← Base de datos SQLite (se autogenera, no tocar)
│   └── cerebro/         ← Tu vault (compatible con Obsidian)
│       ├── raw/
│       │   ├── youtube/     ← Transcripciones de videos
│       │   ├── reuniones/   ← Llamadas de clientes y equipo
│       │   └── documentos/  ← Procesos, decisiones y notas
│       └── wiki/            ← Índices temáticos generados
Paso 5: El archivo maestro CLAUDE.md Acción 5

Crea un archivo llamado CLAUDE.md en la raíz de tu carpeta. Este archivo le explica a Claude quién es y cómo debe responderte.

Archivo: CLAUDE.md 
# CLAUDE.md — Bóveda de conocimiento del negocio
Esta carpeta es la bóveda (segundo cerebro) del dueño de este negocio: todo lo que dijo en videos, reuniones y documentos, guardado como archivos Markdown y buscable en segundos con un índice local SQLite FTS5. Vos (Claude Code) sos el operador de la bóveda: la ponés en marcha, cargás contenido, buscás y respondés citando las fuentes.

Sistema creado por Facundo Corengia (Basdonax AI) — facundocorengia.com.

## Reglas al responder con la bóveda
1. Buscá antes de responder. Cualquier pregunta sobre "qué se dijo", "qué se decidió" o "qué prometimos" se responde corriendo python boveda/buscar.py, nunca de memoria.
2. Citá siempre el archivo fuente (ej: raw/reuniones/2026-01-20_reunion-cliente.md).
3. No inventes. Si la bóveda no tiene el dato, decilo textualmente: "no está en la bóveda".
4. No edites los archivos de raw/ salvo pedido explícito del dueño: son el registro histórico.
5. Privacidad: Nunca guardes contraseñas, tokens o claves dentro de la bóveda.
Paso 6: Puesta en marcha inicial Acción 6

Abre la terminal dentro de tu carpeta (en Windows: haz clic en la barra de direcciones del explorador, escribe powershell y pulsa Enter). Ejecuta Claude y dile la frase de arranque:

Terminal — Iniciar y ordenar el arranque 
claude
Prompt de inicio para pegar en Claude Code 
poné en marcha mi bóveda

Comprobación: Claude Code te hará 3 preguntas sencillas: tu nombre y correo, si tienes canal de YouTube y el idioma de tu contenido. Luego configurará automáticamente boveda/config.py e iniciará la primera prueba de búsqueda.

🧪 Práctica y Prompts Maestros del Sistema Operativo

Una vez montada la Bóveda, es hora de convertirla en tu Sistema Operativo. Utiliza estos prompts exactos para operar y conectar herramientas.

Caso 1

Consulta Forense con Citas Exactas

Cuando necesites recordar un compromiso con un cliente, una cifra o una promesa técnica, pregúntale a Claude Code:

Prompt para Claude Code 
¿Qué le prometimos al cliente Acme Corp respecto al plazo de entrega y los precios de mantenimiento? Buscá en la bóveda y citame las reuniones exactas donde lo dije.

Resultado esperado: Claude Code no inventará nada. Ejecutará python boveda/buscar.py "Acme Corp plazo" y te devolverá los párrafos exactos citando el archivo cerebro/raw/reuniones/2026-03-12_reunion-acme.md.

Caso 2 · Paso 8 Oficial

El Molde para Conectar Cualquier Herramienta

Este es el prompt maestro para enchufar CRMs, pasarelas de pago (Stripe, Mercado Pago) o plataformas externas a tu sistema operativo sin que la IA invente endpoints inexistentes.

Prompt Molde de Conexión Universal 
Quiero conectar [NOMBRE DE LA HERRAMIENTA] a mi sistema.
Antes de escribir código:
1. Fijate si tiene API pública y documentación. Si tiene, decíme qué datos puedo sacar y qué necesito para autenticarme.
2. Si no tiene API, o si la parte que necesito no está en la API, decímelo derecho. No inventes endpoints que no existen: prefiero saber que no se puede antes que descubrirlo cuando el dato está mal.
3. Si no hay API, evaluá las otras vías, en este orden: un feed público, un archivo que yo exporte a mano, o automatizar el navegador entrando a la pantalla como entro yo.
Caso 3

Construir un Dashboard Web Local para tu Negocio

¿Quieres una pantalla única donde ver tus finanzas, operaciones o métricas de clientes sin pagar un SaaS externo? Pídeselo a Claude Code con este estándar estricto:

Prompt Dashboard Web Autónomo 
Construye una aplicación web local de una sola pantalla para visualizar los datos de mi negocio.
Requisitos técnicos obligatorios:
1. Un solo archivo HTML limpio con CSS y JavaScript inline, sin librerías externas pesadas.
2. Los datos se leen desde archivos locales en la carpeta /datos/.
3. Pantalla de propósito único: gráfico visual arriba y tabla detallada abajo con importes y fechas.
4. Debe permitir filtrar por tipo de operación y abrir el detalle de cada cliente.
5. Todo en español claro y adaptado a dispositivos móviles.

⚠️ Errores Frecuentes y Solución Rápida

Problemas típicos documentados en el despliegue del sistema y cómo solucionarlos en 30 segundos.

❌ "python" no se reconoce como un comando interno o externo

Causa: Instalaste Python en Windows pero no marcaste la casilla "Add Python to PATH".

Solución: Vuelve a abrir el instalador de Python, selecciona "Modify" o reinstálalo marcando la casilla de PATH al inicio. Reinicia PowerShell.

❌ Caracteres extraños o rotos al buscar en PowerShell (tildes / ñ)

Causa: La codificación por defecto de la consola de Windows no está sincronizada con UTF-8.

Solución: Ejecuta esta variable de entorno en tu terminal antes de usar el buscador:

PowerShell — Forzar UTF-8 
$env:PYTHONIOENCODING = "utf-8"

❌ El índice SQLite parece viejo o no encuentra archivos recién creados

Causa: Agregaste un archivo .md manualmente pero no ejecutaste la reindexación forzada.

Solución: Corre el comando de reindexado manual. Si sigue extraño, borra la carpeta boveda/_index/; se reconstruirá sola sin perder un solo dato:

Terminal — Reconstruir índice SQLite 
python boveda/buscar.py --reindex

❌ Claude Code empieza a inventar formatos o desordenar carpetas

Causa: Eliminaste o modificaste sin querer el archivo CLAUDE.md en la raíz.

Solución: Restaura el CLAUDE.md oficial (disponible en la pestaña PROCEDIMIENTO). Recuerda: CLAUDE.md es la memoria inmutable del proyecto.
